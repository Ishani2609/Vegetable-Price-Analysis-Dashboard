# Vegetable-Price-Analysis-Dashboard
Interactive Vegetable Price Analysis Dashboard (2025) built using Microsoft Excel 2021, featuring PivotTables, PivotCharts, KPI cards, and slicers to analyze commodity prices, market comparisons, and seasonal trends.



## Project Overview

This project analyzes vegetable price data across multiple markets in 2025 to identify price trends, compare commodities and markets, and explore seasonal price variations.

An interactive dashboard was developed using **Microsoft Excel 2021** to transform raw daily price data into meaningful insights through PivotTables, PivotCharts, KPI cards, and slicers.

## Business Objectives

- Analyze monthly trends in vegetable prices.
- Compare average prices across different commodities.
- Identify price differences across markets.
- Examine minimum, maximum, and modal prices for different vegetables.
- Analyze seasonal variations in vegetable prices.
- Explore market-wise monthly price trends.

## Tools & Technologies

- **Microsoft Excel 2021**
- PivotTables
- PivotCharts
- Excel slicers
- KPI cards
- Data analysis and visualization

## Dataset Overview

The dataset contains daily vegetable price records for the year 2025.

| Column | Description |
|---|---|
| Date | Date of the price record |
| Market | Market where the price was recorded |
| Commodity | Vegetable name |
| Variety | Variety of the vegetable |
| Min_Price | Minimum recorded price |
| Max_Price | Maximum recorded price |
| Modal_Price | Modal price |

The dataset covers six commodities across four markets.

## Dashboard Features

### KPIs
- Overall Average Modal Price
- Highest-Priced Commodity
- Highest-Priced Market
- Total Commodities

### Visualizations

1. Monthly Trend of Average Vegetable Prices
2. Average Price Comparison by Commodity
3. Average Commodity Prices Across Different Markets
4. Average Vegetable Prices by Market
5. Average Minimum, Maximum and Modal Prices by Commodity
6. Highest Recorded Price by Commodity Across Markets
7. Seasonal Trends in Average Vegetable Prices
8. Monthly Vegetable Price Trends Across Markets

### Interactive Filters

The dashboard includes slicers for:

- Commodity
- Market
- Season

These filters allow users to interact with the dashboard and explore the price data based on selected criteria.
